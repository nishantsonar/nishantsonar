# 💫 About Me:
### 👨‍💻 Hi there! I'm **Nishant Sonar**  

I’m a **Java Full Stack Engineer** with **3 years of experience** in designing and building **scalable, high-performance web applications**. My expertise spans **Spring Boot**, **ReactJS**, and **PostgreSQL**, with deep focus on **microservices architecture**, **API design**, and **system integration**.

I’m passionate about solving complex problems through clean architecture and automation. Currently, I’m developing:
- A **Job Search Aggregator** using *Spring Boot + ReactJS + PostgreSQL* that consolidates job listings from multiple sources into a single intelligent search interface.  
- A **Microservices-based E-Commerce System** including an *Authentication Server*, *API Gateway*, *Config Server*, *Cart & Product Services*, and *Notification Service*.

I thrive in agile environments and enjoy taking ownership across the full development lifecycle — from backend architecture and API integration to frontend UI and deployment automation.

**Here’s what I specialize in:**
- **Backend:** Java, Spring Boot, Spring Cloud (Eureka, Config Server, API Gateway), Microservice Architecture, RESTful APIs  
- **Frontend:** ReactJS, JavaScript (ES6+), HTML5, CSS3  
- **Databases:** PostgreSQL, MySQL, MongoDB  
- **DevOps & Tools:** Docker, Kubernetes (Beginner), Jenkins, Maven, Git, Postman  
- **Cloud & Security:** AWS (Basic EC2/S3), JWT Authentication, Role-based Access Control
